# AFTERHOP app pages

Public product, support, and privacy pages for AFTERHOP by CpoApps.

- Home: https://cpoapps.github.io/afterhop-site/
- Support: https://cpoapps.github.io/afterhop-site/support.html
- Privacy: https://cpoapps.github.io/afterhop-site/privacy.html

Static HTML and CSS, published by GitHub Pages from `main` at the repository root. No build or external runtime dependencies. Support contact follows the existing CpoApps GitHub issue-tracker pattern.

The privacy page describes the current no-live-ad gameplay beta. Update its policy, App Store disclosures, and consent configuration before enabling live advertising or adding data services.
